# 测试计划 · 麦麦营养搭配咪

## 1. 测试目标

验证四件事：

1. **约束是硬的**——过敏原、忌口、预算任何一条都不能被「尽量」绕过；
2. **推荐是可用的**——3 个套餐结构完整、字段齐全、理由与假设可读；
3. **轮换是真的**——连续点击不重复，候选不足时给可执行建议而不是白屏；
4. **降级是诚实的**——没有实时数据时，UI 必须让人一眼看出「演示模式」。

## 2. 环境

| 项 | 值 |
|---|---|
| 运行环境 | Windows 11 / 浏览器直开 `index.html`（`file://`，无需服务器） |
| Node | 22.x（仅测试用，无第三方依赖） |
| Python | 3.11+（仅数据构建用） |
| 数据 | `data/mcp_snapshot.json`：门店 1450713，抓取 2026-10-22 22:25，32 条商品 |

## 3. 测试分层

```
单元测试（Node / vm 沙箱，22 条）      → 数据层、过滤、组合、评分、轮换
集成测试（MCP 三连调 + 构建脚本）      → 真实接口 → 快照 → 镜像 → 前端可读
UI 测试（浏览器 test.html + 手测）      → 三态、徽章、气泡、卡片字段
验收测试（对照 8 条需求）               → 逐条打勾
```

## 8. 已知未覆盖与风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 真实门店 SKU 远多于营养表条目 | 部分商品无法推荐 | 明示「只推荐能确证营养的商品」，快照记录 `joinNotes` |
| 过敏原靠关键词映射 | 可能误判/漏判 | `exceptKeywords` 例外表 + README 与 UI 双重声明 |
| 糖为碳水折算 | 数值偏差 | 标记 `sugarEstimated`，文档说明 |
| 未覆盖多浏览器实机 | 兼容性未知 | 仅用标准 DOM/CSS，无框架依赖；`file://` 与 `http://` 均可运行 |
| 未做下单链路 | 无交易验证 | 有意为之，见 `MCP_INTEGRATION.md` §2 |
